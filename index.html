🎮 Player Class: Paddle Power

The Player class defines how each player's paddle operates. It handles its position, size, speed, and movement based on keyboard input (or AI control). Player 1 typically uses Arrow keys, while Player 2 uses W/S keys in two-player mode. It also includes the fire() method to launch the ball when a player serves (using the Spacebar). Think of this as giving each paddle its own brain and rules! 🧠🕹️


class Player {
    constructor(id, side) {
        this.el = document.getElementById(id); // The HTML element
        if (!this.el) throw new Error(`Player element not found: ${id}`);
        this.side = side; // 'left' or 'right'
        this.height = PADDLE_HEIGHT;
        this.width = PADDLE_WIDTH;
        this.speed = PLAYER_SPEED;
        // Initial position (centered vertically)
        this.y = (game.clientHeight - this.height) / 2;
        this.el.style.top = `${this.y}px`; // Set initial visual position
    }

    // Update player state each frame
    update(deltaTime) {
        let dy = 0; // Change in y-position
        if (!gameRunning) return; // Don't move if game isn't running

        // --- Determine movement based on keys pressed and game mode ---
        if (gameMode === '1p') {
            if (this.side === 'left') { // Player 1 controls
                if (keysPressed['arrowup'] || keysPressed['w']) dy = -this.speed;
                if (keysPressed['arrowdown'] || keysPressed['s']) dy = this.speed;
            }
            // In 1p, right paddle is AI - movement handled by AI class
        } else { // 2p mode
            if (this.side === 'left') { // Player 1 controls
                if (keysPressed['arrowup']) dy = -this.speed;
                if (keysPressed['arrowdown']) dy = this.speed;
            } else if (this.side === 'right') { // Player 2 controls
                if (keysPressed['w']) dy = -this.speed;
                if (keysPressed['s']) dy = this.speed;
            }
        }

        // Apply movement if keys are pressed
        if (dy !== 0) this.move(dy);

        // Fire the ball if space is pressed and this player owns the ball
        if (keysPressed[' '] && ball.owner === this) this.fire();
    }

    // Move the paddle vertically and update its visual position
    move(dy) {
        const newY = this.y + dy;
        const maxY = game.clientHeight - this.height; // Max Y position
        // Clamp position within game boundaries
        this.y = Math.max(0, Math.min(newY, maxY));
        this.el.style.top = `${this.y}px`; // Update CSS
    }

    // Launch the ball from the paddle
    fire() {
        if (ball.owner === this) { // Can only fire if owning the ball
            // Calculate initial angle (slightly random)
            let angle = (Math.random() - 0.5) * Math.PI / 6; // Small random angle

            // Aiming assist for AI serve (optional complexity)
            if (gameMode === '1p' && this.side === "right" && player1) {
                 // ... (AI aiming logic as in original code) ...
                 const playerCenterY = player1.y + player1.height / 2;
                 const paddleCenterY = this.y + this.height / 2;
                 const targetY = game.clientHeight / 2 + (playerCenterY - paddleCenterY) * 0.2; // Bias factor 0.2
                 const deltaY = targetY - (this.y + this.height / 2);
                 const targetAngle = Math.atan2(deltaY, game.clientWidth * 0.8); // Aim towards player side distance
                 angle = Math.max(-MAX_BOUNCE_ANGLE * 0.8, Math.min(targetAngle, MAX_BOUNCE_ANGLE * 0.8));
            }

            const directionX = this.side === "left" ? 1 : -1; // Fire away from paddle
            // Set ball's velocity vector
            ball.velocity = [
                directionX * currentBallSpeed * Math.cos(angle),
                currentBallSpeed * Math.sin(angle)
            ];
            ball.owner = null; // Release the ball
        }
    }

    // Helper function to get the center Y coordinate of the paddle
    getCenterY() {
        return this.y + this.height / 2;
    }
}

⚽ Ball Class: Movement, Reset, and Visuals

The Ball class manages everything about the ball: its position, size, speed, and direction (velocity). It handles movement, bouncing off the top/bottom walls, and resetting its position after a point is scored or when the game starts. It also updates the ball's visual position on the screen. If a player is set as the owner, the ball will follow that player's paddle until fired. Collision detection with paddles is handled separately in the main game loop. ⚽️💨


class Ball {
    constructor() {
        this.el = ballEl; // The HTML element for the ball
        if (!this.el) throw new Error("Ball element not found");
        this.size = BALL_SIZE;
        this.reset(null); // Initialize position and state
    }

    // Reset ball to initial state (center or attached to owner)
    reset(ownerInstance = null) {
        this.owner = ownerInstance; // Assign owner if serving
        currentBallSpeed = INITIAL_BALL_SPEED; // Reset speed

        if (this.owner) {
            // If owned, position next to the owner's paddle
            this.followOwner();
            this.velocity = [0, 0]; // No movement until fired
        } else {
            // If not owned, position in the center
            this.x = (game.clientWidth - this.size) / 2;
            this.y = (game.clientHeight - this.size) / 2;
            // Give initial random velocity
            const angle = (Math.random() * Math.PI / 2) - Math.PI / 4; // -45 to +45 deg
            const directionX = Math.random() < 0.5 ? 1 : -1; // Random start direction
            this.velocity = [
                directionX * currentBallSpeed * Math.cos(angle),
                currentBallSpeed * Math.sin(angle)
            ];
            this.owner = null; // Ensure owner is null
        }
        this.updateVisual(); // Set initial visual position
    }

    // Update ball's position each frame
    update(deltaTime) {
        // Only move if game is running OR ball is owned (needs to follow paddle)
        if (!gameRunning && !this.owner) return;

        if (this.owner) {
            this.followOwner(); // Stick to the owner paddle
        } else {
            // Move the ball based on velocity
            this.x += this.velocity[0];
            this.y += this.velocity[1];

            // Bounce off top and bottom walls
            if (this.y <= 0) {
                this.y = 0; // Prevent sticking
                this.velocity[1] *= -1; // Reverse vertical velocity
            } else if (this.y >= game.clientHeight - this.size) {
                this.y = game.clientHeight - this.size; // Prevent sticking
                this.velocity[1] *= -1; // Reverse vertical velocity
            }
            // Note: Paddle collisions and scoring checks happen outside this method
        }
        this.updateVisual(); // Update CSS position
    }

    // Position the ball next to its owner's paddle
    followOwner() {
        if (!this.owner) return;
        const ownerCenterY = this.owner.y + this.owner.height / 2;
        this.y = ownerCenterY - this.size / 2; // Center vertically with paddle

        // Position horizontally next to the paddle
        if (this.owner.side === "left") {
            this.x = this.owner.el.offsetLeft + this.owner.width + 5; // Right of left paddle
        } else { // 'right' side
            this.x = this.owner.el.offsetLeft - this.size - 5; // Left of right paddle
        }
    }

    // Update the ball's CSS style to match its internal position
    updateVisual() {
        if (this.el) {
            this.el.style.left = `${this.x}px`;
            this.el.style.top = `${this.y}px`;
        }
    }
}

🤖 AI Class: Mastering the Paddle

The AI class defines how the computer-controlled opponent behaves in 1-player mode. It takes a Player object to control. The AI predicts where the ball will land on its side of the court and moves its paddle to intercept it. The difficulty level (set via setDifficulty) affects its reaction time (reactionDelay), movement speed (maxSpeedMultiplier), prediction accuracy (predictiveError), and how quickly it serves the ball (fireDelay). It makes the AI feel more human (or superhuman!). ⚡️


class AI {
    constructor(playerToControl) {
        this.ctl = playerToControl; // The Player object the AI controls
        // Default difficulty settings (can be changed by setDifficulty)
        this.difficultyFactor = 0.7; // General skill level
        this.reactionTimer = 0; // Timer for delaying reaction
        this.reactionDelay = 180; // Time in ms AI waits before reacting
        this.fireTimer = 0; // Timer for delaying serve
        this.fireDelay = 600; // Time in ms AI waits before firing
        this.predictiveError = 0.15; // Randomness in prediction (0 = perfect)
        this.maxSpeedMultiplier = 1.0; // Max speed relative to player speed
        this.setDifficulty('normal'); // Apply default normal settings
    }

    // Adjust AI parameters based on selected difficulty
    setDifficulty(level) {
        switch(level) {
            case 'easy':
                this.difficultyFactor = 0.4; this.reactionDelay = 300; this.fireDelay = 800;
                this.predictiveError = 0.3; this.maxSpeedMultiplier = 0.8; break;
            case 'normal':
                this.difficultyFactor = 0.7; this.reactionDelay = 180; this.fireDelay = 600;
                this.predictiveError = 0.15; this.maxSpeedMultiplier = 1.0; break;
            case 'hard':
                this.difficultyFactor = 1.0; this.reactionDelay = 100; this.fireDelay = 400;
                this.predictiveError = 0.08; this.maxSpeedMultiplier = 1.2; break;
            case 'veryHard':
                this.difficultyFactor = 1.3; this.reactionDelay = 50; this.fireDelay = 250;
                this.predictiveError = 0.04; this.maxSpeedMultiplier = 1.4; break;
            case 'impossible':
                this.difficultyFactor = 1.8; this.reactionDelay = 0; this.fireDelay = 150;
                this.predictiveError = 0.01; this.maxSpeedMultiplier = 1.6; break;
            default: this.setDifficulty('normal'); break; // Fallback
        }
    }

    // Update AI state each frame
    update(deltaTime) {
        if (!gameRunning) return; // Do nothing if game isn't running

        // --- Handle Firing ---
        if (ball.owner === this.ctl) { // If AI owns the ball
            this.fireTimer += deltaTime;
            if (this.fireTimer >= this.fireDelay) {
                this.ctl.fire(); // Fire the ball
                this.fireTimer = 0; // Reset timer
            }
            return; // Stop here if AI owns the ball
        } else {
            this.fireTimer = 0; // Reset fire timer if not owning the ball
        }

        // --- Handle Movement ---
        this.reactionTimer += deltaTime;

        // React only after delay AND if ball is moving towards AI (right side)
        if (this.reactionTimer >= this.reactionDelay && ball.velocity[0] > 0) {
            // --- Predict ball's landing position ---
            const paddleX = this.ctl.el.offsetLeft;
            const distanceToPaddle = paddleX - (ball.x + ball.size);
            const ballSpeedX = Math.max(Math.abs(ball.velocity[0]), 1);
            const timeToReach = distanceToPaddle / ballSpeedX;
            let predictedBallY = ball.y + ball.velocity[1] * timeToReach;

             // Add random error based on difficulty
             const errorAmount = (Math.random() - 0.5) * 2 * this.predictiveError * this.ctl.height;
             predictedBallY += errorAmount;

            // Basic wall bounce prediction
             let bounces = 0;
             const gameHeight = game.clientHeight; const ballHeight = ball.size;
             while ((predictedBallY < 0 || predictedBallY > gameHeight - ballHeight) && bounces < 3) {
                 predictedBallY = (predictedBallY < 0) ? -predictedBallY : 2 * (gameHeight - ballHeight) - predictedBallY;
                 bounces++;
             }
             predictedBallY = Math.max(0, Math.min(predictedBallY, gameHeight - ballHeight)); // Clamp prediction

            // --- Move Paddle ---
            const targetPaddleCenterY = predictedBallY + ball.size / 2;
            const currentPaddleCenterY = this.ctl.getCenterY();
            const deadZone = (this.ctl.height * 0.1) / Math.max(this.difficultyFactor, 0.1);
            let dy = 0;

            if (currentPaddleCenterY < targetPaddleCenterY - deadZone) dy = this.ctl.speed * this.maxSpeedMultiplier;
            else if (currentPaddleCenterY > targetPaddleCenterY + deadZone) dy = -this.ctl.speed * this.maxSpeedMultiplier;

            if (dy !== 0) this.ctl.move(dy);

        } else if(ball.velocity[0] <=0 ){
             // Reset reaction timer if ball moves away from AI
             this.reactionTimer = 0;
        }
    }
}

⚙️ Core Game Logic Functions

These functions orchestrate the game flow, handling initialization, starting/stopping, updates, collisions, scoring, and user interactions with controls.

initializeGame()

Sets up the game state when the page loads or when the game section is shown. Creates player, ball, AI objects, resets scores, positions paddles, applies settings from controls (colors, difficulty, etc.), populates the music list, and updates UI elements like instructions and button states. It ensures everything is ready before the user clicks "Start Game".

startGame()

Called when the "Start Game" button is clicked. Sets gameRunning to true, resets scores and game state, applies current settings, potentially starts music, resets the ball (giving it an initial velocity), and kicks off the main game loop using requestAnimationFrame(update).

pauseGameLoop(winnerMessage)

Stops the game loop by setting gameRunning to false and cancelling the animation frame. Clears pressed keys, pauses music. If a winnerMessage is provided, it displays it (usually via alert) and resets the ball/undo state.

handleResetGame()

Called by the "Stop & Reset" button. Stops the current game (using pauseGameLoop) and then completely re-initializes the game to its default state using initializeGame().

update(time)

The heart of the game loop. This function is called repeatedly by the browser (via requestAnimationFrame). It calculates the time elapsed since the last frame (deltaTime), updates the positions and states of the player(s), ball, and AI, checks for collisions (checkCollisions), checks if anyone scored (checkScored), and then requests the next frame, continuing the loop as long as gameRunning is true. It includes error handling to stop the game if something goes wrong during an update.

checkCollisions() ⚡️

Checks if the ball has collided with either paddle. It only checks if the ball is moving towards the specific paddle and overlaps vertically. If a collision occurs, it calculates a bounce angle based on where the ball hit the paddle (higher hit = upward angle, lower hit = downward angle), reverses the ball's horizontal direction, applies the new vertical velocity based on the angle, increases the ball's speed slightly, and nudges the ball away from the paddle to prevent sticking.

checkScored() 🏆

Checks if the ball has gone past the left or right edge of the game area. If so, it identifies the scoring player, saves the score state for the "Undo" feature, increments the score by pointsPerScoreValue, updates the displayed score, and checks if the win condition (winScoreLimit) has been met. If a player wins, it triggers a win animation (triggerWinAnimation) and stops the game (pauseGameLoop) with a win message. If no one won, it resets the ball (ball.reset()), potentially giving possession to the player who was scored upon (if ballPossessionOnScore is true).

Other Helper Functions

Includes functions like updateScoreDisplay, updateInstructions, resetPaddles, changeDifficulty, handleModeChange, handleMusicSelection, toggleFullscreen, etc., which handle UI updates and respond to user interactions with the control panel options.
